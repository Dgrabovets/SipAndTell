# API сервера

Сервер: ASP.NET Core на .NET 10, один процесс. Раздаёт клиент из `wwwroot`, API под `/api` и вебхук бота под `/bot`.

## Настройки

Всё секретное берётся из окружения, в репозитории их нет.

| Переменная | Что это |
|---|---|
| `Telegram__BotToken` | токен бота, по нему проверяется подпись Mini App |
| `Telegram__WebhookSecret` | секрет вебхука, Telegram присылает его в заголовке `X-Telegram-Bot-Api-Secret-Token` |
| `ConnectionStrings__Default` | строка подключения к PostgreSQL |

## Вход

Каждый запрос под `/api` несёт заголовок `Authorization: tma <initData>`, где `initData` это строка запуска Mini App (`webApp.initData`). Сервер проверяет подпись HMAC-SHA256 от токена бота и срок (24 часа). Без верной подписи ответ 401.

## Чаепития

- `GET /api/evenings?limit=50` свои чаепития, новые первыми. Чужие не возвращаются.
- `POST /api/evenings` добавить. Тело: `teaId` известного чая или `newTeaName` и `newTeaType` (`Oolong`, `Green`, `Puer`, `Black`, `White`), `score` от 1 до 10 или `null`, `place` (`Home`, `Work`, `Friends`, `Road`), `time` (`Morning`, `Day`, `Evening`), `mood` из 8 чисел от 0 до 1, `effects` из 7 чисел от 0 до 1, `review`, `drankAt` (по умолчанию сейчас). Новый чай получает состояние «ждёт проверки» и виден только автору. Ответ 201. Ошибка в данных 400, чужой или неизвестный чай 404.
- `DELETE /api/evenings/{id}` удалить своё. Чужое выглядит как несуществующее, ответ 404.

Порядок осей настроения: бодро, радостно, любопытно, уютно, устало, грустно, раздражённо, тревожно. Порядок осей эффекта: взбодрил, успокоил, согрел, собрал мысли, разморило, поднял настроение, взвинтил.

## Каталог

- `GET /api/catalog?text=&limit=50` проверенные чаи и свои, ждущие проверки. Чужие непроверенные не возвращаются.

## Черновики

Файл не сохраняется, он только разбирается. Сейчас вместо ИИ имитация, которая всегда возвращает один черновик.

- `POST /api/drafts/photo` (multipart, поле `file`, до 15 МБ): название и тип чая.
- `POST /api/drafts/voice` (multipart, поле `file`): оценка, место, время, настроение, эффекты, отзыв словами человека.

## Бот

- `POST /bot/update` вебхук Telegram. Без верного секрета ответ 404.

Бот разбирает присланные фото, голосовые и видео (звук видео как голосовое), отвечает в чат и после успешного разбора удаляет присланное сообщение. При сбое сообщение остаётся, человек может отправить его снова. Хранится только текст, аудио и видео не сохраняются.
