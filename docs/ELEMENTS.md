# Элементы интерфейса главной

Каждый элемент обсуждается отдельно: у него есть несколько вариантов, они переключаются в панели «Вид» в правом верхнем углу (видна только при `npm run dev`). Выбор запоминается в браузере. Когда владелец выбирает вариант, остальные удаляются.

## Решено

| Элемент | Решение |
|---|---|
| Общий стиль | жидкое стекло, тёмная тема, палитра «Дом» |
| Шрифт | Jost |
| Карточка чаепития | строка, окрашена в цвет чая, плотная |
| Карточка: содержимое | название слева, тип чая по центру между названием и оценкой, оценка справа |
| Карточка: оценка | кольцо, цвет по оценке (зелёный, янтарный, красный) |
| Карточка: появление в списке | выезд слева |
| Карточка: отклик на нажатие | сжатие, рябь от точки касания перетекает в детали |
| Карточка: жест | свайп влево, под ней «Изменить» и «Удалить» |
| Список | группы «Сегодня», «Вчера», «На этой неделе», «На прошлой неделе», дальше по месяцам |
| Детали | шторка в цвет чая, закрывается крестиком |
| Детали: шапка | название и тип слева, оценка маленьким полукругом цвета оценки справа |
| Детали: настроение | радар из 8 вершин, заголовок и строка словами |
| Детали: обстоятельства | значки с подписями |
| Детали: отзыв | линия слева цвета чая |
| Детали: друзья | одна шкала, у каждого друга свой цвет (способ подписи выбираем) |
| Кнопки действий в деталях | главная и меню «⋯», с анимациями |
| Шапка | приветствие и сводка недели |
| Кнопка «Выпил» | круглая справа внизу, без бликов и ряби |
| Карточка создания | выезжает снизу, по всей её ширине снизу вверх поднимается пар |
| Навигация | сверху: Дневник, Друзья, Каталог, активный раздел отмечен точкой |

## Выбираем (панель «Вид»)

| Группа | Варианты |
|---|---|
| Календарь: где живёт | лента дней под шапкой; кнопка в шапке и шторка с месяцем |
| Детали: друзья на шкале | точки и легенда; буквы в точках; имена над и под шкалой |
| Кнопка «Выпил»: как видно, что она живая | без анимации; мягкая пульсация; подпись «Выпил» |

## Не сделано

- Форма «Выпил» (содержимое шторки).
- Календарь: решить, где он живёт, и что показывает день без чая (сейчас пустое состояние с подсказкой).
- Экран статистики и графиков, вкладка в навигации (идея записана).
- Пустое состояние и загрузка.
- Иконки, вибрация, звуки.
