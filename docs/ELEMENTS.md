# Элементы интерфейса главной

Каждый элемент обсуждается отдельно: Claude предлагает 2–3 способа с живым примером в `web/`, владелец выбирает. Статус обновляется после решения.

| Элемент | Статус |
|---|---|
| Общий стиль: жидкое стекло, тёмная тема, палитра «Дом» | решено |
| Шрифт Jost | решено |
| Рябь при нажатии: волна идёт по всему экрану и по шторке (2,8 с) | решено, скорость на проверке |
| Карточка чаепития: детали открываются шторкой | решено (владелец за шторку) |
| Детали: настроение шестиугольником (радар, цветок или колесо), обстоятельства значками, короткий отзыв, друзья, действия | выбираем вид шестиугольника |
| Карточка: что видно сразу (название, тип, оценка, настроение, день) | не обсуждали |
| Оценка: цифра, звёзды или шкала | не обсуждали |
| Чипы (тип, настроение, день) | не обсуждали |
| Шапка и заголовок, сводка недели | не обсуждали |
| Кнопка «Выпил»: форма и место | не обсуждали |
| Форма «Выпил» (шторка) | не обсуждали |
| Навигация: главная, друзья, каталог | не обсуждали |
| Пустое состояние и загрузка | не обсуждали |
| Иконки, вибрация, звуки | не обсуждали |
