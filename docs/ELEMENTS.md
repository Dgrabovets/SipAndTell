# Элементы интерфейса главной

Каждый элемент обсуждается отдельно: у него есть несколько вариантов, они переключаются в панели «Вид» в правом верхнем углу (видна только при `npm run dev`). Выбор запоминается в браузере. Когда владелец выбирает вариант, остальные удаляются.

## Решено

| Элемент | Решение |
|---|---|
| Общий стиль | жидкое стекло, тёмная тема, палитра «Дом» |
| Шрифт | Jost |
| Карточка чаепития | строка, окрашена в цвет чая, плотная |
| Карточка: содержимое | название слева, тип чая по центру между названием и оценкой, оценка справа |
| Карточка: оценка | кольцо, цвет по оценке (зелёный, янтарный, красный) |
| Карточка: появление в списке | выезд слева |
| Карточка: отклик на нажатие | сжатие, рябь от точки касания перетекает в детали |
| Карточка: жест | свайп влево, под ней «Изменить» и «Удалить» |
| Календарь | кнопка в шапке, шторка шириной до 400 px, кнопка «Сегодня», тап по числу соседнего месяца переключает месяц, всегда 6 рядов с днями соседних месяцев, месяцы листаются со сдвигом, чашки дня под месяцем теми же карточками без свайпа, высота списка меняется плавно, рябь входит в детали снизу |
| Список | группы «Сегодня», «Вчера», «На этой неделе», «На прошлой неделе», дальше по месяцам |
| Детали | шторка в цвет чая с ползунком вверху, закрывается крестиком или смахиванием; полос прокрутки в приложении нет |
| Детали: вкладки | «Моё чаепитие» и «О чае» (справка от ИИ), текст с подчёркиванием цвета чая и свайпом вбок |
| Детали: шапка | название и тип слева, оценка маленьким полукругом цвета оценки справа |
| Детали: настроение | радар из 8 вершин, плавная капля, после роста движение затихает на значениях и не выходит за радар, у каждого настроения свой рисунок (бодро один вдох наружу, радостно прыжки, любопытно поворот, уютно дыхание, устало провисание сверху, грустно оседание, раздражённо дёрганье, тревожно дрожь), заголовок и строка словами |
| Детали: обстоятельства | значки с подписями |
| Детали: отзыв | линия слева цвета чая |
| Детали: друзья | одна шкала, у каждого друга свой цвет, под ней небольшая легенда |
| Кнопки действий в деталях | главная и меню «⋯», с анимациями |
| Шапка | приветствие и сводка недели столбиками: кубик цвета чая на каждую чашку |
| Кнопка «Выпил» | круглая справа внизу, мягкая пульсация кольца |
| Карточка создания | выезжает снизу; пар отдельным слоем играет один раз, не прерывается кликами и закрытием карточки, к концу расходится за её границы |
| Шрифт подписей | Manrope в навигации, сводке и вкладках, остальное Jost |
| Детали: эффект чая | вкладка «Эффект», полоски с пружиной, числа справа у каждой полоски с одной десятой, между эффектами тонкая линия, у сравнения чаёв яркие цвета типов (одинаковые типы: второй бирюзовый), ты янтарный, друзья сиреневые, два режима: «Ты и друзья» (твоя оценка и среднее по друзьям) и «С другим чаем»; семь осей, названия как в дневнике: взбодрил, успокоил, согрел, собрал мысли, разморило, поднял настроение, взвинтил |
| Навигация | по центру сверху: Дневник, Друзья, Каталог, активный раздел отмечен точкой |

## Выбираем (панель «Вид»)

| Группа | Варианты |
|---|---|
| Форма «Выпил»: кнопки съёмки | три плитки сверху; панель внизу, видна при прокрутке; большой микрофон, остальное мелко |

## Сделано в отсутствие владельца (проверить утром)

| Что | Как проверить |
|---|---|
| Хранилище чашек: добавление, правка, удаление, «Выпить ещё раз», сохранение в браузере | форма «Выпил» сохраняет чашку, свайп и меню в деталях правят и удаляют (с подтверждением) |
| Экраны «Друзья», «Каталог», «Графики» | четыре вкладки навигации |
| Пустое состояние дневника, друзей, каталога, графиков | очистить данные браузера и зайти |
| Вибрация Telegram, звук сохранения (выключатель в шапке), кнопка «Назад» Telegram | вибрацию и «Назад» видно только в Telegram |
| Настоящая запись голоса | кнопка «Голосом» просит микрофон, при отказе идёт имитация |
| Кнопки съёмки формы: три вида | панель «Вид», выбрать вид |

## Не сделано

- Загрузка списка (скелет карточек) появится с сервером.
- Подключение клиента к серверу, друзья и статистика на сервере, модерация каталога, миграции PostgreSQL, настоящая модель ИИ.
- Оценка в форме сейчас обязательна для сохранения, по замыслу она необязательна.
- Видео в README, проверка на реальном телефоне и в Telegram.
