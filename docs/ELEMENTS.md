# Элементы интерфейса главной

Каждый элемент обсуждается отдельно: у него есть несколько вариантов, они переключаются в панели «Вид» в правом верхнем углу (видна только при `npm run dev`). Выбор запоминается в браузере. Когда владелец выбирает вариант, остальные удаляются.

| Элемент | Статус |
|---|---|
| Общий стиль: жидкое стекло, тёмная тема, палитра «Дом» | решено |
| Шрифт Jost | решено |
| Рябь на карточке: рождается в карточке и перетекает в шторку | решено, скорость на проверке |
| Детали открываются шторкой, закрываются крестиком | решено |
| Настроение: радар из 8 вершин, заголовок и строка словами | решено, набор вершин на проверке |
| Кнопки действий в деталях: главная и меню «⋯», с анимациями | решено |
| Карточка на главной: строка | решено |
| Оценка: кольцо | решено |
| Чипы на карточке: таблетки, тип чая и настроение в своих цветах, настроение формулировкой | решено |
| Шапка: приветствие и сводка недели | решено |
| Кнопка «Выпил»: круглая справа внизу | решено, анимация выбирается (рябь, пар, свечение) |
| Карточка создания, появление: выезд, круг из кнопки, приближение | выбираем |
| Навигация сверху: Дневник, Друзья, Каталог | решено, анимация выбирается (скольжение, желе, точка) |
| Друзья в деталях: полоски | решено, вид выбирается (полоски, ячейки, одна шкала) |
| Обстоятельства в деталях: значки | решено |
| Форма «Выпил» (содержимое шторки) | не делали |
| Экран статистики и графиков, вкладка в навигации | идея записана, не делали |
| Пустое состояние и загрузка | не делали |
| Иконки, вибрация, звуки | не обсуждали |
