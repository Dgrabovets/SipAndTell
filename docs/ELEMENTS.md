# Элементы интерфейса главной

Каждый элемент обсуждается отдельно: у него есть несколько вариантов, они переключаются в панели «Вид» в правом верхнем углу (видна только при `npm run dev`). Выбор запоминается в браузере. Когда владелец выбирает вариант, остальные удаляются.

## Решено

| Элемент | Решение |
|---|---|
| Общий стиль | жидкое стекло, тёмная тема, палитра «Дом» |
| Шрифт | Jost |
| Детали чаепития | открываются шторкой, закрываются крестиком |
| Настроение | радар из 8 вершин, заголовок и строка словами (набор вершин на проверке) |
| Кнопки действий в деталях | главная и меню «⋯», с анимациями |
| Шапка | приветствие и сводка недели |
| Кнопка «Выпил» | круглая справа внизу |
| Навигация | сверху: Дневник, Друзья, Каталог |
| Обстоятельства в деталях | значки с подписями |
| Чипы | таблетки, тип чая и настроение в своих цветах, настроение формулировкой |

## Выбираем (панель «Вид»)

| Группа | Варианты |
|---|---|
| Карточка: поверхность | цвет чая, однотонная, полоска слева, светящаяся рамка |
| Карточка: плотность | просторная, плотная |
| Карточка: появление в списке | всплытие, слева, проявление, без |
| Карточка: отклик на нажатие | приподнять, 3D-наклон, сжатие |
| Карточка: оценка | кольцо, цвет по оценке, полукруг |
| Карточка: что в чипах | тип, настроение, день; тип и настроение; с иконками места |
| Список: группировка | общий, по дням |
| Карточка: жест | нет, свайп с действиями |
| Детали: шапка | название и тип, с большим кольцом |
| Детали: отзыв | цитата, рамка, линия слева |
| Детали: друзья | полоски, ячейки, одна шкала |
| Карточка создания: появление | выезд, круг из кнопки, приближение |
| Кнопка «Выпил»: анимация | рябь, пар, свечение |
| Навигация: анимация | скольжение, желе, точка |

## Не сделано

- Форма «Выпил» (содержимое шторки).
- Экран статистики и графиков, вкладка в навигации (идея записана).
- Пустое состояние и загрузка.
- Иконки, вибрация, звуки.
