# Sip & Tell

Черновик, 2026-11-18. Обсуждён с владельцем, правится по ходу.

## Что это

Telegram Mini App с ботом: чайный дневник для друзей. Бот открывает приложение кнопкой и шлёт уведомления, экраны рисует Mini App. Приложение переделано по идеям из Nightpour («Что я пью»): владелец перестал пить, друзья заинтересовались чаем.

## Решения

- Название: Sip & Tell (в коде `SipAndTell`).
- Аудитория первого круга: только друзья владельца, публичного запуска нет.
- Сервер нужен: бот, проверка подписи Telegram, общие оценки друзей. Вариант A: один процесс ASP.NET Core (клиент, API, вебхук бота) и PostgreSQL.
- Клиент: React, TypeScript, Vite, Motion для анимаций. Образцы блоков берутся с 21st.dev и переписываются.
- Хостинг: VPS и домен с HTTPS ещё не выбраны. Для разработки локальный туннель.

## Хочу (из Singularity)

- Оценки чая и сравнение с оценками друзей.
- Друзья по приглашению-ссылке.
- Настроение и обстоятельства чаепития.
- Свой отзыв.
- Модерация новых чаёв.
- Из Nightpour: фото упаковки и обстановки, ненайденный чай виден автору и попадает в каталог после проверки, место по желанию, прогресс.

## Предложение для первого круга (не согласовано)

Вход через Telegram, список чаёв, «выпил» с оценкой, настроением и отзывом. Друзья и сравнение оценок вторым шагом. ИИ, загрузчики из внешних баз, геолокация и учёба позже.
